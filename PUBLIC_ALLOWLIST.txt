# PUBLIC_ALLOWLIST
#
# Source of truth for which paths may live in the public mirror of acidbase.
# Used in two places:
#   1. git filter-repo --paths-from-file PUBLIC_ALLOWLIST.txt
#      (history is rewritten to keep only these paths; everything else is dropped)
#   2. .github/workflows/public-allowlist.yml
#      (CI fails any PR that touches a path not in this list)
#
# Format: one path or glob per line. Blank lines and lines starting with `#` are ignored.
# filter-repo accepts glob via --paths-from-file when the line contains '*'; otherwise
# it is treated as a literal path prefix. The CI guard uses `grep -E` patterns derived
# from this file (see workflow).
#
# Add a new entry only after confirming the file/dir contains no internal references
# (ledger, project codenames, internal hosts, ACIDVUCA portfolio details).
#
# This list is deliberately default-DENY and enumerates files individually, so
# forgetting an entry holds a file back rather than leaking one. The cost is
# that a NEW module can be omitted while a published module imports it, which
# once shipped an unimportable public package. `acidbase push` now guards that
# case: the pre-flight resolves every intra-package import in the projection
# and refuses a public destination when one does not resolve. Prefer fixing the
# omission here over passing `--skip-projection-check`.

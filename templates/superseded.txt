# Superseded template versions, one per line: <template path> <sha256>.
#
# The digest is sha256 over the UTF-8 text after stripping a BOM and
# normalizing CRLF to LF, i.e. the same comparison `acidbase scaffold` uses.
# A child file that matches one of these verbatim is an *old acidbase
# baseline*, not local policy; scaffold reports it as `stale` and rewrites
# it only under `--refresh-baseline`. Anything that matches neither the
# current template nor an entry here stays `preserve`.
#
# tests/test_scaffold.py walks git history and fails when a historical
# template blob is missing here, so every template change must append the
# digest of the version it replaces. Compute with:
#   python -c "import hashlib,sys;print(hashlib.sha256(open(sys.argv[1],'rb').read().decode('utf-8-sig').replace('\r\n','\n').encode()).hexdigest())" <file>
